NTranslate — cách gọi đúng từng phần UI

Xem sơ đồ chú thích trên ảnh thật · Tên biến, tên chức năng và selector thực tế trong Sources/translate/. Dùng đúng tên này khi mô tả bug hoặc yêu cầu sửa.

Cấu trúc dọc của popup dịch: Title bar (chrome) → Main pane (split source/result) → Main action row → Subtranslate section (split + action row riêng) → Q&A section. Ô nhập câu hỏi qaInputField nằm cạnh action row của pane đang được hỏi.
Cửa sổ Study là cửa sổ riêng (NSWindow tiêu đề "Study"), không phải popup dịch. Mở bằng reviewButton / openReviewWindow. Bên trong, ReviewWindowController chỉ hiện một Screen tại một thời điểm: home → session / newWords / passages → summary. Gọi đúng tên màn hình, đừng gọi cả cửa sổ là "popup Learn".

11. Question type — ReviewPlanner.QuestionKind

Tám ô trên modeGrid. Ô đầu là Auto (requestedKind == nil), không phải một case của enum. Mỗi thẻ trong phiên gọi ReviewPlanner.resolve(requested:interval:repetitions:available:); mode không có dữ liệu trên thẻ rơi về Flip kèm ghi chú trên hintLabel.

Ô trên HomeKindCách hỏi trong session
Auto — New cards start with recognition…nil → autoKindThẻ mới: Flip. Interval tăng dần: Cloze → Contrast → Recall → Listen
Flip — See the word, grade yourself….flipActiveQuestion.none. Hiện từ, bấm Show Answer, tự chấm Again/Hard/Easy
Cloze — Fill in the missing word….clozeActiveQuestion.typed. Ô answerField, Return = submitTypedAnswer()
Recall — See the meaning, type the word.recallCùng typed; prompt là nghĩa, đáp án là từ gốc
Listen — Hear the word, then type it.listenCùng typed; đọc audio rồi gõ từ
Contrast — Pick the right word….contrastActiveQuestion.contrast. Hai nút firstChoiceButton / secondChoiceButton
Collocation — Type the common pairing….collocationTyped: gõ cụm đi kèm từ nghĩa
Family — Type a related form….familyTyped: gõ dạng cùng họ từ gloss

Typed / Contrast tự chấm bằng ReviewPlanner.autoGrade (đúng nhanh ≤ 6s = Easy; gần đúng 1 ký tự = Hard). Flip luôn tự chấm tay. Gọi đúng question type / modeTiles, đừng gọi "chế độ học" — tên đó dành cho lối vào phiên ở mục 12.
