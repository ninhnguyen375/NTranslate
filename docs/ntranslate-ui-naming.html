NTranslate — cách gọi đúng từng phần UI

Xem sơ đồ chú thích trên ảnh thật · Tên biến, tên chức năng và selector thực tế trong Sources/translate/. Dùng đúng tên này khi mô tả bug hoặc yêu cầu sửa.

Cấu trúc dọc của popup: Title bar (chrome) → Main pane (split source/result) → Main action row → Subtranslate section (split + action row riêng) → Q&A section. Ô nhập câu hỏi qaInputField nằm cạnh action row của pane đang được hỏi.

0. Cách gọi cụm icon trên header pane

Code gọi chúng là trailingIcons — tham số của layoutPaneChrome (PopoverController+Layout.swift:421), đặt trên sourceHeaderBar / resultHeaderBar. Dùng đúng tên này, đừng đặt tên mới kiểu "toolbar" hay "action group".

CụmCách gọiThành phần
Cụm icon góc phải ô nguồnsource pane trailing icons[speakSourceButton, speakSourceSlowButton]
Cụm icon góc phải ô kết quảresult pane trailing icons[speakResultButton, speakResultSlowButton, retryButton, copyButton, saveWordButton]
Cụm icon ô nguồn khu Subtranslatesub source pane trailing iconssubSection.[speakSourceButton, speakSourceSlowButton]
Cụm icon ô kết quả khu Subtranslatesub result pane trailing iconssubSection.[speakResultButton, speakResultSlowButton, retryButton, copyButton, saveWordButton, closeButton]
Cụm icon khu Q&AQ&A pane trailing iconsqaSection.[copyButton, closeButton]
