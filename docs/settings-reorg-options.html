Chọn 1 trong 3. Xanh = mục/nhóm mới, cam = chuyển từ tab khác sang.

Hiện trạng & vấn đề

4 tab hiện tại
  • General — Theme, API Key, Source/Target/Native Language, Maximum Length, Daily Reviews, Copy, Paste, Speech
  • Prompts — 6 prompt
  • Languages — bảng Source / Target
  • Advanced — API Base URL, Model, Connection, Speech Provider/URL/Key/Models/Fallback, History Folder, Panel W×H, Density, 5 hotkey, Hotkey Conflicts
  • Advanced quá tải: 17+ hàng trộn 4 chủ đề khác nhau (LLM, speech, cửa sổ, hotkey) trong một danh sách phẳng, không heading.
  • API Key ở General, API Base URL + Model ở Advanced — cùng một nhóm bị tách hai tab.
  • Speech bị xé ba chỗ: checkbox prefetch ở General, provider/URL/key ở Advanced, model per-language ở giữa Advanced.
  • Language trùng lặp: popup chọn ngôn ngữ ở General nhưng danh sách nguồn lại ở tab Languages.
  • Hotkey không có nhóm riêng dù chiếm 6 hàng.
  • General là túi rác: theme + ngôn ngữ + giới hạn + clipboard + speech đứng ngang hàng.

Được thêm
  • Search lọc theo tên setting
  • Thêm mục sau này không giới hạn
  • Deep-link từ popup vào đúng mục
  • Giống Settings gốc của macOS, quen tay nhất về lâu dài.
  • Search giải quyết luôn bài toán "setting này nằm đâu".
  • Mở đường cho mục mới mà không phải sắp lại tab lần nữa.
  • Viết lại toàn bộ khung SettingsWindowController, tốn công gấp nhiều lần A và B.
  • Search cần index tên setting, thêm code state.
  • Nút Cancel/Revert/Save phải bố trí lại cho hợp layout mới.
